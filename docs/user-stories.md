# User Stories & Requirements

## 1. Search & Discovery
* **US01:** As a user, I want to search for a book, so that I can find the specific title I am looking for.
* **US02:** As a user, I want to view a list of all books, so that I can see what is available on the platform.
* **US03:** As a user, I want to filter the books list, so that I can narrow down my search results.
* **US04:** As a user, I want to access the book detail page, so that I can view its full information.

## 2. Recommendations
* **US05:** As a user, I want to view a personalized book recommendations section, so that I can discover books matching my preferences.

## 3. User Authentication
* **US06:** As a user, I want to create an account, so that I can gain access to personalized website features.
* **US07:** As a user, I want to log into my account, so that I can access my profile and saved preferences.
* **US08:** As a user, I want to log out of my account, so that I can safely leave the session.

## 4. Favorites (Logged-in only)
* **US09:** As a logged-in user, I want to favorite a book, so that I can save it and improve my personalized recommendations.
* **US10:** As a logged-in user, I want to remove a book from my favorites, so that I can keep my saved list and recommendations relevant.
* **US11:** As a logged-in user, I want to view my list of favorite books, so that I can revisit the titles I saved.
